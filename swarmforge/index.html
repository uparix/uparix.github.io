SwarmForge

Disciplined agents build better software — faster and more reliably.

Open a herdr workspace with one pane per claude or opencode agent, each able to message its peers across panes.

Prerequisite

brew install herdr

Install

curl -fsSL https://www.uparix.com/swarmforge/install.sh | sh

Usage

python swarmforge.py [claude|opencode]

Pass claude or opencode to pick the CLI directly; without it you're asked to choose. You then select which agents to launch.
